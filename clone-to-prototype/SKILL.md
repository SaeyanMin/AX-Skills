# clone-to-prototype

## 개요

로컬에 클론된 프론트엔드 레포의 **현행 화면 코드를 읽어서**, 외부 의존성이 전혀 없는 정적 3파일(`index.html` / `style.css` / `index.js`) 프로토로 포팅한다. 로컬 서버 없이 `open index.html`로 브라우저에서 바로 확인한다.

**대전제**: 참고할 프론트엔드(및 필요시 백엔드) 레포지토리가 **이미 로컬에 클론되어 있다**. 라이브 앱을 실행(`npm run dev` 등)하지 않는다. 디자인·구조·라벨·분기·스타일은 전부 클론된 레포의 소스코드(컴포넌트·CSS·i18n 문구)를 읽어서 재현한다.

**산출물 범위**: 프로토 3파일만. spec/기획 문서는 이 스킬의 범위 밖이다.

## 시작 절차 (코드 읽기 전 반드시 수행)

`AskUserQuestion`으로 아래를 확정한 **뒤에야** 코드를 읽고 포팅을 시작한다.

```
1) 대상 프론트엔드 레포가 로컬에 클론돼 있는가?
     └ 안 돼 있으면 → 클론부터 하도록 안내하고 여기서 중단. (앱을 실행하지 않는다)
2) 어떤 레포지토리(로컬 경로)를 참고하는가?
     └ 필요하면 관련 백엔드 레포 경로도 함께 확인 (분기·상태·라벨의 근거)
3) 어떤 화면/컴포넌트를 프로토로 만드는가?
     └ 화면 이름·라우트·컴포넌트 파일을 특정. 애매하면 후보를 나열해 고르게 한다.
4) 3파일을 어디에 생성하는가? (출력 경로)
     └ 참고 레포를 오염시키지 않도록, 매번 사용자에게 물어 지정된 폴더에 생성한다.
```

이 4가지가 확정되기 전에는 코드를 읽지 않는다.

## 포팅 방법 (소스코드 → 프로토)

라이브 화면을 보는 게 아니라 **소스를 근거로 재현**한다.

- **구조/마크업**: 대상 화면 컴포넌트를 읽고 DOM 계층·순서·시맨틱을 그대로 옮긴다.
- **라벨/문구**: i18n 파일·상수·하드코딩 문자열에서 **실제 표시 텍스트**를 가져온다. 지어내지 않는다.
- **스타일**: 컴포넌트가 참조하는 CSS/스타일 정의(색·간격·타이포·상태별 스타일)를 읽어 `style.css`로 옮긴다. 눈대중 금지.
- **분기/상태**: 조건부 렌더링(로딩/에러/빈 상태/권한/토글)을 소스에서 확인하고, 필요한 상태는 `index.js`에서 순수 DOM 조작으로 재현한다. 데이터가 필요하면 백엔드 레포의 응답 형태를 참고해 **정적 목데이터**로 인라인한다.
- **이미지/아이콘**: 외부 URL로 불러오지 않는다. 인라인 SVG나 CSS로 그린다.

## 정적 3파일 규칙 (반드시 준수)

**금지**

| 항목 | 이유 |
|------|------|
| 외부 CDN/폰트/CSS/JS/이미지 URL | 자체완결 위반. 전부 인라인/CSS로 그린다 |
| 프레임워크·라이브러리 (React/Vue/jQuery 등) | Vanilla JS만 사용 |
| ES module (`type="module"`, `import`/`export`) | classic script만 사용 |
| `localStorage` / `sessionStorage` | 스토리지 접근 금지 |
| `alert` / `confirm` / `prompt` | 네이티브 다이얼로그 금지 |
| `window.open` / `location` 이동 | 페이지 이탈 금지 |
| `eval` | 금지 |
| `document.body`에 직접 append | 금지 |

**필수**

- `index.js`는 `DOMContentLoaded`로 감싸지 말고 **IIFE**로 즉시 실행: `(function(){ ... })();`
- DOM은 `#app` 등 **컨테이너 요소에 append** (body 직접 조작 금지)
- 주요 블록에 **안정적인 `id`** + **시맨틱 태그**(`<header>`/`<nav>`/`<main>`/`<section>`/`<button>` 등) 사용
- HTML은 `index.html`이 `style.css`와 `index.js`를 로컬 상대경로로 참조

## 출력 & 확인

1. 3파일 각각을 **코드블록으로 출력**한다.
2. 동시에 지정된 출력 경로에 **실제 파일로 생성**한다.
3. 로컬 HTTP 서버를 띄우지 않는다. `open <경로>/index.html`로 브라우저에서 바로 연다.

## 흔한 실수

- 라이브 앱을 실행해 화면을 보려 함 → 금지. 소스만 읽는다.
- 문구/색을 눈대중으로 추정 → i18n·CSS 소스에서 실제 값을 가져온다.
- 편의상 CDN(폰트·아이콘·CSS 프레임워크) 링크 → 자체완결 위반. 인라인한다.
- `DOMContentLoaded` 래핑 → IIFE 즉시 실행으로 바꾼다.
- 참고 레포 폴더 안에 프로토를 생성해 레포를 오염 → 출력 경로를 별도로 지정받는다.
- 비밀정보(토큰·사내 URL·비공개 경로·사내 코드베이스명)를 프로토에 포함 → 절대 금지.
